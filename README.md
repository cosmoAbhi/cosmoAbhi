# Abhishek Das

I recently completed my Ph.D. in Physics at Penn State. I build numerical simulations and data analysis workflows in Python and C++ for astrophysics and applied data science.

## Featured projects

| Project | What it does |
| --- | --- |
| [SafeFlow](https://github.com/Erdos-Projects/fall-2026-safeflow) | Erdős Institute team project that used Caltrans PeMS data to forecast freeway congestion up to 30 minutes ahead. We compared tree models and a Transformer on a held-out period and evaluated warning lead time and false-alert burden. |
| [RABBIT](https://sites.google.com/view/rabbitcode/home) | Scientific computing project that tracks relativistic charged particles through electromagnetic fields using a C++ integrator and Python tools for trajectory and energy analysis. |
| [tov](https://github.com/cosmoAbhi/tov) | Models the structure of relativistic stars with the Tolman–Oppenheimer–Volkoff equations and computes tidal metric perturbations. |
